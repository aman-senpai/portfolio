# GitHub token
- This project reads the GitHub API token from `GITHUB_TOKEN`.
- Copy `.env.example` to `.env` locally and set `GITHUB_TOKEN` there.
- Never commit a real personal access token to this repository.
```
GITHUB_TOKEN=YOUR_OWN_ACCESS_TOKEN
```
